# Add a private read-only report

Read CLAUDE.md and views.json. Establish the question and who will read the report. Add a named read-only SELECT view with a new migration when needed, then a views.json entry with selected columns. Use the shared renderer and brand.json. Run npm test and npm run view -- <name>. Inspect the resulting HTML and show its private path. Do not add buttons, sends or a web server; do not expose personnel records publicly.
