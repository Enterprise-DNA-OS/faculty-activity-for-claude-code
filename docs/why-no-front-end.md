# The coordinator talks; the record stays readable

The base is for a trusted coordinator who works with selected activity records. Private HTML reports show the return queue, evidence gaps and privacy checks. Commands record changes and prepare documents.

A staff portal provides role-based self-service, mobile forms, sign-in and concurrent editing that this local workspace does not provide. This base has no mobile app, offline synchronisation, attachment upload, drag and drop, live university connections or public profiles. It does not replace the scholarly data service or promotion workflow.

Enterprise DNA can build the agreed staff experience and connections into a custom version. Keep the existing services until the agreed replacement is tested. No screen is needed to test and use this coordinator record today.
